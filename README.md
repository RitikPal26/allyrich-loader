# Allyrich Loader - 3D Interactive Phone Screen

Interactive 3D phone screen loader built with **Next.js**, **React**, **Tailwind CSS**, and **Spline 3D**.

## Features

- 📱 **Interactive 3D Phone Model**: Photorealistic 3D phone held in hand with dynamic reflections and lighting.
- 🎨 **Custom Screen Mapping**: Customized texture mapping placing the custom AR emblem directly onto the 3D phone screen mesh (`Place your image here 2`).
- ⚡ **No Watermarks**: Native WebGL pipeline watermark removal for clean presentation.
- 🚀 **Next.js App Router**: Modern, fast setup ready for deployment on Vercel or any hosting provider.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/)
- **3D Engine**: [@splinetool/react-spline](https://spline.design/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
